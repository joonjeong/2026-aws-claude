# Datalake Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** hub와 완전히 독립적인 수집 프로세스가 6개 소스의 원본을 디렉토리 레이크(JSONL)에 적재하고, 옵션으로 자체 SQLite에 정규화본을 저장한다.

**Architecture:** `shared/datalake` 독립 패키지. 소스당 1개의 순수 코어 클라이언트(fetch/normalize, 저장 무지) + FileSink/SqliteSink + labkit 폴러/스트림으로 조립하는 runner. 스펙: `docs/specs/2026-08-11-datalake-design.md`.

**Tech Stack:** Python 3.11+, labkit(editable path dep), httpx, feedparser, websockets; market만 optional extra(yfinance·pykrx).

## Global Constraints

- `hub.*`/`app.*` import 절대 금지 — Task 1의 AST 독립성 테스트가 게이트
- `lab.db` 접근 금지; 자체 루트 `DATALAKE_ROOT`(기본 `shared/datalake/data/`)만 사용
- 수집 주기 기본값은 hub와 동일: quake 60s, news 120s, trend 60s, market 30s(장중 45s/장외 600s 실효 게이트), contrail 600s/60s, wake 상시 스트림 + 플러시 10s
- 정규화 로직은 hub 모듈과 동일 동작으로 이식(값 복사·코드 이식, import 금지). 이식 시 반드시 hub 원본 파일을 읽고 대조
- 싱크 실패는 best-effort: 로그만 남기고 수집 계속
- 키 없으면 해당 소스만 비활성(trend: `YT_API_KEY`, wake: `DATALAKE_AIS_KEY`), 프로세스는 정상 기동
- 커밋은 datalake 관련 파일만 명시적으로 스테이징 (작업 트리에 무관한 contrail 수정분 존재)
- 테스트 실행: `cd shared/datalake && uv run pytest`

**Interfaces (Produces):**
```python
# core/source.py
@dataclass(frozen=True)
class Record:
    source: str; kind: str; payload: Any; meta: dict; fetched_at: float
@dataclass(frozen=True)
class Job:
    name: str; interval_s: float; fetch: Callable[[], Awaitable[list[Record]]]
class PollSource(Protocol):
    id: str
    def jobs(self) -> list[Job]: ...
class StreamSource(Protocol):
    id: str; url: str
    def subscribe_payload(self) -> dict | None: ...
    def parse(self, raw: str | bytes) -> list[Record]: ...
# core/sinks.py
class FileSink:
    def __init__(self, root: Path): ...
    def write(self, records: Sequence[Record]) -> None  # raw/<source>/<kind>/dt=YYYY-MM-DD/part-HH.jsonl append
```

### Task 2: Runner + CLI(`--once`)

**Files:**

**Interfaces:**

```python
class Runner:
    def __init__(self, poll_sources, stream_sources, sinks): ...
    async def run_once(self) -> int          # 모든 poll job 1회 실행, 레코드 수 반환 (stream은 건너뜀+로그)
    async def start(self) / async def stop(self)  # 폴러+스트림+플러시 잡 기동
    def status(self) -> dict                  # collector status 취합
# sources/__init__.py
AVAILABLE: dict[str, Callable[[], BuildResult | None]]   # None = 비활성(사유 로그)
# __main__.py: python -m datalake run [--sources quake,news] [--once]
```

**Steps:**
- [ ] 실패 테스트: FakePollSource(job 1개, Record 1건 반환) + FakeSink(리스트 수집)로 `run_once()`가 1 반환·sink에 1건 도달; sink가 raise해도 run_once 정상 완료; FakeStreamSource의 parse 결과가 flush 잡으로 sink 도달(수동 flush 호출)
- [ ] FAIL 확인 → Runner/CLI 구현 → PASS
- [ ] 커밋: `feat(datalake): runner + CLI --once`
